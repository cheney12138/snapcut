# Snapcut 产品功能定义文档（02-product-spec）

## 1. 产品一句话定位

**Snapcut 是一款 macOS 原生质感的截图工具：按下快捷键、框选、松手即得，标注顺手，复制即走——不在截图上浪费一秒钟。**

一句话补充：它做的是「原生截图该有但没有的一切」，而不是「所有截图软件功能的大全」。

---

## 2. 目标用户

| 用户群 | 特征 | 核心场景 |
|---|---|---|
| **主力：开发者 / 设计师 / 产品经理** | 每天截图 10+ 次，截完立刻贴进 issue、PR、Figma、飞书/Slack | 框选 UI 局部 → 加个箭头 → 复制粘贴进聊天框，全程 < 10 秒 |
| **次主力：技术写作者 / 客服 / 运营** | 需要给截图配编号、文字说明，量大但操作简单 | 截图 → 标序号 → 保存归档 |
| **不覆盖**：重度后期用户、录课讲师、需要批量 OCR 流水线的人 | 他们的需求属于专业工具范畴 | ——（见 Non-goals） |

用户画像一句话：**「我用系统自带截图已经够快了，但它截完那一瞬间我总要再花 5 秒做点它做不了的事。」** Snapcut 解决的就是这 5 秒。

---

## 3. 核心交互原则（可执行设计规则）

以下每条都是验收时可逐条对照的设计规则。总纲三条，细则若干。

### 总纲

- **P0 原生感优先**：所有 UI 使用 AppKit 原生控件与系统字体、系统圆角、系统阴影；不做自定义皮肤、不做暗色模式之外的任何主题。视觉验收标准：把 Snapcut 的任意面板截图和系统截图（Cmd+Shift+5）并排摆放，普通用户分不出是谁的。
- **P1 松手即终态**：任何一次鼠标操作结束后，产品必须处于「要么已经完成、要么一步可达完成」的状态。不允许「松手后还要点确认按钮」的流程。
- **P2 功能做减法**：新增任何功能前先问「原生截图 + CleanShot/Shottr 里我实际用过的是哪 20%？」。只有两问都答得上才允许进路线图。Snow Shot 是反面教材：功能全，但每次截图都在菜单里迷路。

### 交互细则（规则编号即验收项）

- **R1 全局快捷键**：默认 `Cmd+Shift+A` 触发区域截图（可自定义，但必须有默认值且与系统截图不冲突）；`Cmd+Shift+S` 触发全屏截图。按 Esc 任何时刻可无副作用取消。
- **R2 框选手感**：按下快捷键后屏幕立即变暗、鼠标变为精细十字线（复刻 Cmd+Shift+4 行为）；拖拽过程中实时显示选区尺寸（宽×高像素标签跟随选区右下角）。
- **R3 松手即标注态**：框选完成后**松开鼠标即进入标注态**——选区四周出现原生工具条（悬浮于选区下方，放不下时自动翻转到上方），此时截图尚未输出、尚未保存，处于「草稿态」。
- **R4 Enter 即复制退出**：标注态下按 **Enter = 复制到剪贴板并退出**；按 **Cmd+S = 弹出保存面板**；按 **Esc = 丢弃本次截图并退出**。三个按键零菜单、零鼠标。
- **R5 双击即走**：标注态下**双击选区内任意位置 = 复制并退出**（等价于 Enter），这是给纯鼠标用户的高速通道。
- **R6 工具条只保留 6 个工具**：箭头、矩形框、文字、马赛克、序号、高亮。图标顺序固定，热键 1–6 直选。超出 6 个的一律进后续版本评审，默认拒绝。
- **R7 标注零弹窗**：选中任何标注工具后立即生效，属性（颜色/粗细）通过工具条上的原生 Popover 调整，绝不弹模态对话框；标注时鼠标在选区内就是画笔，移出选区则忽略。
- **R8 撤销只用 Cmd+Z**：标注态支持无限步撤销/重做（Cmd+Z / Cmd+Shift+Z），不提供「撤销按钮 + 历史」双轨。
- **R9 截图后自动进剪贴板通知**：复制成功后仅出现一条系统通知样式的小缩略图（点击可打开编辑器），2 秒后自动消失，不占 Dock、不弹窗打断。
- **R10 历史零配置**：每次输出的截图自动进入本地历史（保留最近 30 条），通过菜单栏图标查看；不要求用户设置任何东西。
- **R11 滚动不干扰**：Snapcut 的任何面板都不拦截系统的截图快捷键、不修改全局键盘行为；与 Cmd+Shift+3/4/5 完全共存。
- **R12 首次运行零教学**：首次启动只显示一个原生风格的快捷键说明小窗（一屏、三行字、一个「开始使用」按钮），之后永不打扰。

## 4. MVP 功能清单（每项带验收标准）

> MVP 判定原则：只有「没有它，用户就必须回到系统截图或另一款工具」的功能才进 MVP。

### F1 区域截图（P0 核心）
框选任意区域，松手即得。
**验收标准**：
- 按 Cmd+Shift+A → 拖拽 → 松手，全程 < 300ms 响应，无卡顿；
- 松手后进入标注态（R3），Enter 后图片（PNG，含 Retina 2x）已在剪贴板；
- Esc 任何阶段均可取消且不留任何残留窗口；
- 多显示器（含不同缩放比）下像素坐标正确。

### F2 全屏与窗口截图（P0）
**验收标准**：
- Cmd+Shift+S 全屏截图直接进标注态；
- 框选时悬停自动高亮当前窗口边界（参考 Shottr），点击即选中整窗；
- 悬停高亮延迟 < 100ms，选中窗口边界带原生蓝色描边。

### F3 基础标注：箭头 / 矩形 / 文字（P0）
**验收标准**：
- 工具条 6 工具中的前三个可用（R6），热键 1/2/3 切换；
- 箭头支持拖拽定方向，矩形拖拽定大小，文字点击后出系统输入框；
- 颜色默认红/黑/白三选一（Popover），粗细三档；
- Cmd+Z 撤销逐步生效（R8），标注完成后 Enter 复制的是**含标注**的最终图。

### F4 复制与保存双通道（P0）
**验收标准**：
- Enter = 复制退出（R4）；Cmd+S = NSSavePanel 原生保存；
- 复制后系统通知缩略图出现并在 2 秒消失（R9）；
- 剪贴板内容可粘贴到 Finder（落盘）、Pages、浏览器，格式为 PNG。

### F5 马赛克（P0）
**验收标准**：热键 4；拖拽涂抹区域即打码，块大小固定两档；撤销可用；打码后无法通过像素还原（非模糊而是像素化）。

### F6 历史记录（P1，MVP 内）
**验收标准**：
- 最近 30 条自动保存（R10），菜单栏图标点开为原生 NSMenu 列表（缩略图 + 时间）；
- 点击历史项 = 复制该图到剪贴板；历史文件存本地沙盒目录，可一键清空。

### F7 滚动截屏（长截图）（P1，MVP 末尾）
**验收标准**：
- 在浏览器/普通窗口内触发后，自动识别滚动容器并边滚边拼接；
- 拼接结果进入标注态，重合区域自动去重；拼接失败（不识别容器）时给出明确提示并回退为普通截图，绝不卡死。

### F8 延迟截图（P2）
**验收标准**：菜单栏可选 3s / 5s 倒计时后进入框选；倒计时期间有原生 HUD 显示剩余秒数，Esc 可取消。

### MVP 完成的判定
用户从「想截图」到「图片已在别人屏幕上」的全流程 ≤ 10 秒，且中途零弹窗、零学习成本（新用户不看说明也能猜对每个按键）。

## 5. 迭代路线 v0.1 → v1.0（每期只加 1–2 个功能）

| 版本 | 新增功能（严格 1–2 个） | 说明 |
|---|---|---|
| **v0.1** | F1 区域截图 + F4 复制/保存双通道 | 最小可用闭环：框选 → Enter → 剪贴板。没有标注也能替代系统截图 |
| **v0.2** | F2 全屏与窗口截图 | 补齐截图形态；窗口高亮是体验分水岭 |
| **v0.3** | F3 基础标注（箭头/矩形/文字） | 进入「贴进 issue 前顺手补一刀」的核心场景 |
| **v0.4** | F5 马赛克 + R6 工具条定型 | 工具满 6 个后工具条冻结，此后增工具需走评审 |
| **v0.5** | F6 历史记录 | 修复「刚截的图手滑丢了」这个高频痛点 |
| **v0.6** | F7 滚动长截图 | 第一重量级功能，独立成期便于打磨拼接质量 |
| **v0.7** | F8 延迟截图 + 稳定性打磨 | 只加轻量功能，为 1.0 做性能与兼容性收口 |
| **v0.8** | 序号标注 + 高亮（R6 中剩余两工具） | 补齐技术写作场景，工具条至此完整 |
| **v0.9** | 公测期：只修 bug、调手感 | 冻结功能面；根据公测反馈优化框选手感与通知 |
| **v1.0** | 正式发布 | 承诺：安装即用、无账户、无订阅提醒、离线可用 |

**路线图纪律**：任何一期不得挤入第三项功能；想加的功能先排进 backlog，下期评审时用 P2 原则（「我实际用过的是哪 20%」）裁决。

## 6. 明确不做（Non-goals）及理由

| 不做 | 理由 |
|---|---|
| **录屏 / GIF 导出** | 录屏是完全不同的工程复杂度（编码、音频、时间轴编辑），CleanShot 已做得极好；做了必然拖累截图手感，违反 P2 |
| **OCR 文字识别 / 翻译** | Snow Shot 式的功能堆砌；识别质量参差、用户频次低，且 macOS 系统已内置（Live Text） |
| **云同步 / 账户体系 / 订阅墙** | 截图是本地瞬时操作，账户摩擦直接违反「松手即终态」；v1.0 承诺无账户 |
| **贴图（钉在桌面）功能** | 看似高频，实则与 Snipaste 用户群重叠、且会引入常驻窗口管理复杂度；观察数据后再议 |
| **AI 增强（自动去背景、智能修图）** | 与「不在截图上浪费时间」的核心诉求相反——AI 处理意味着等待 |
| **团队协作 / 云相册 / 分享链接** | 属于协作平台赛道，超出单机工具边界 |
| **自定义皮肤 / 主题 / 个性化工具栏** | 违反 P0 原生感原则；工具条顺序冻结（R6） |
| **Windows / Linux 版本** | 「原生质感」的前提是 AppKit + 系统控件，跨平台必然牺牲核心卖点 |
| **复杂图片编辑（图层、裁剪旋转、滤镜）** | 那是 Preview / Pixelmator 的职责；Snapcut 只做截图上的一笔标注 |
