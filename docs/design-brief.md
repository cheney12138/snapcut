# Snapcut 视觉设计 Brief（HTML 预览用）

> 目标：把 Snapcut（macOS 原生质感截图工具）的完整 UI 体系做成一页 HTML 交互原型。
> 风格基调：**经典 Apple 原生 + 玻璃质感（vibrancy/material）的高级感**。
> 参考气质：macOS Sequoia/Tahoe 系统控件、CleanShot X 的克制、原味 NSVisualEffectView 磨砂。

## 产品一句话

按下快捷键、框选、松手即得，标注顺手，复制即走——不在截图上浪费一秒钟。

## 视觉体系（Token 建议）

- **玻璃材质**：所有浮层用半透明磨砂（backdrop-filter: blur(30px) saturate(180%)），
  背景带 4-8% 白（浅色模式）/ 55% 黑（深色模式）；圆角 10-12px 连续曲率观感
- **描边**：玻璃层外沿 1px 半透明白（rgba(255,255,255,.25) 内描边），底部投影大而柔
- **字体**：-apple-system 栈；标题 13pt semibold，控件 12pt regular，辅助 11pt
- **色板**：系统语义色（label/secondaryLabel/tertiaryLabel）；强调色 = 系统蓝 #0A84FF/#007AFF
- **动效**：微反馈 120-180ms ease-out（hover/press）；面板出场 240ms spring(0.3, 1.2)；
  通知自动消失前 200ms 淡出；**绝不出现弹跳循环**
- **标注色板**（5 色）：#FF3A30 红 / #007AFF 蓝 / #FFD60A 黄 / #000000 黑 / #FFFFFF 白

## 需要原型化的场景（一页内分区展示，可切换浅色/深色）

### 1. 状态栏图标
- 模板图标：四角选区括号 + 中心圆点（黑/白随菜单栏自适应），悬停高亮

### 2. 框选 HUD
- 屏幕变暗 25%，十字准星光标
- 拖拽中：白色 1.5px 双层描边选框 + 右下角黑底白字胶囊尺寸角标（812×476@2x）
- 悬停窗口：系统蓝描边自动吸附高亮（v0.2 功能）

### 3. 编辑器工具栏（核心！）
- 位置：选区正下方居中 12px，磨砂玻璃条，内容：
  - 6 工具：箭头/矩形/文字/马赛克/序号/高亮（SF Symbols 风格图标 + tooltip 显示热键 1-6）
  - 分隔线 → 5 色圆点（当前色白描边）→ 粗细 3 档
  - 分隔线 → 撤销/重做 → 隐藏(H) → 复制(↩ 主按钮、蓝色) → 保存(⌘S) → 取消(Esc)
- **交互**：工具 hover 抬起 2px + 背景亮 8%；选中态 = 蓝底白字胶囊；
  主按钮「复制」用系统蓝实心
- **动效**：工具栏从选区底边 spring 滑入（y: +8→0, opacity 0→1, 240ms）

### 4. 复制成功通知（R9）
- 右下角 2 秒自动消失：缩略图（56px 高、圆角 8）+ 「已复制到剪贴板」+ 右侧「编辑」按钮
- 玻璃材质，出现 200ms ease-out，消失前 200ms 淡出

### 5. 历史面板（菜单栏下拉，v0.5）
- 菜单栏图标点开：400px 宽玻璃下拉
- 每行：缩略图 64×40 + 相对时间（刚刚/5 分钟前）+ 悬停出现「复制」按钮
- 顶部：最近 30 条标题；底部：清空历史（红字）
- 滚动惯性、行 hover 蓝色高亮 8%

### 6. 权限引导浮窗（贴身拖拽源浮窗）
- 贴在「系统设置」窗口右下角内侧：磨砂 HUD 窗
- 左：48px App 图标（蓝底白括号，可拖拽、拖起时放大 1.08 + 投影加深）
- 右：主文案「拖我到「屏幕录制」列表」+ 副文案「松手即完成授权」
- 交互：图标 hover 时光标变抓取；拖拽中浮窗冻结
- 右上 ✕ 关闭

### 7. 首次运行引导窗（R12）
- 一屏三行：「Snapcut 已就绪 / ⌘⇧A 框选截图 / Enter 复制到剪贴板」+ 主按钮「开始使用」
- 玻璃卡居中，标题 15pt，快捷键用 kbd 胶囊样式（灰底、白描边、圆角 6）

### 8. 滚动截图模式（v0.6，占位展示）
- 框选后右侧出现竖向进度指示：细长玻璃胶囊，内部蓝色填充随拼接进度增长，
  完成时变成对勾闪一下；提示文案「滚动内容，自动拼接中」

## 工程要求

- 单文件 HTML（内联 CSS/JS），无外部依赖（图标用内联 SVG，画 SF Symbols 风格线条）
- 深浅色双模式：默认跟随 prefers-color-scheme + 右上角切换开关
- 布局：一页纵向滚动分区展示 8 个场景，每场景有标题和简注；
  场景 2/3 做在一个「模拟屏幕」（16:10 深色壁纸背景）里，可真实交互：
  拖拽出选框、工具栏出现、点击工具切换选中态
- 动效可感知但不喧宾夺主
