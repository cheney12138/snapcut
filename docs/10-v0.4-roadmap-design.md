### 2.1 功能 #1：已画标注二次编辑（Select / Move / Reshape / Inline Text Re-edit / Delete）

#### 交互设计（极简零工具栏膨胀）
1. **默认进入方式（无新按钮）**：
   - 在编辑态切回无工具状态（默认态 `.none`，或再按一次当前工具数字键 `1–7` / 工具栏当前按钮取消选中），画布即为「选择与移动态」；
   - **命中已有标注**：单击选中该标注（显示克制的 Apple 风格选中蓝框 + 白色描边圆形操控柄）；拖拽本体整体平移，拖拽端点/四角柄精准改变形状；
   - **未命中标注（空白区）**：保持原有「拖动整体移动选区」行为，**零体验回退**；
   - **快捷原地改字**：无论是 `.none` 态还是 `.text` 工具态，**双击已有文字标注**均原地唤出 `GlassTextField`（预填原文字、原字号、原颜色），编辑回车即原地更新（单次 `⌘Z` 撤销），清空提交即删除该文字标注；
   - **选中态联动**：
     - 选中标注时点击工具栏颜色点或拖动线宽滑杆 → **实时修改当前选中标注**的 `colorIndex` / `strokeWidth`（同时更新当前工具默认样式）；
     - 选中标注时按 `Delete` / `Backspace` → 仅删除选中标注（支持 `⌘Z` 恢复）；
     - 选中标注时按方向键 `↑↓←→` → 微调该标注位置 1pt（`Shift` = 10pt），不再误动选区框；
     - 选中标注时按 `Esc` → **优先取消标注选中态**，再次按 `Esc` 才退出整个截图会话。
   - 保持 `AnnotationStore` 撤销栈整洁：拖拽平移/调柄过程仅预览，松手且有真实变更时**只压一次 `undoStack`**。

#### 架构落位
- **Core / Domain（新增 + 扩展）**：
  - 新增 `Sources/Core/Domain/AnnotationEditing.swift`：
    - `AnnotationHandle`：`.body`、`.start`、`.end`（箭头/高亮）、`.topLeft` / `.topRight` / `.bottomLeft` / `.bottomRight`（矩形/马赛克/椭圆）；
    - `AnnotationHitResult(index: Int, handle: AnnotationHandle)`；
    - `AnnotationEditorGeometry` 纯算法命名空间：
      - `boundingRect(for:textSize:)`（含文字测量闭包注入，不依赖 AppKit）；
      - `handles(for:textSize:)` 返回可拖拽操控点列表；
      - `hitTestHandle(point:in:textSize:tolerance:)`（优先命中已选中标注的操控柄）；
      - `hitTestBody(point:in:annotations:textSizeProvider:tolerance:)`（倒序从顶层命中；矩形/椭圆命中描边环 ±8pt，避免覆盖内部其他标注；马赛克/文字/序号命中实体面积）；
      - `transformed(_:handle:delta:)` 纯函数计算平移与拉柄后的新 `AnnotationModel`（保证最小尺寸、椭圆中心/半径同步更新、箭头/高亮端点精确跟随）。
  - 扩展 `Sources/Core/Domain/AnnotationModel.swift`（`AnnotationStore`）：
    - `replace(at:with:pushUndo:)`、`commitExternalSnapshot(_:)`（拖拽前保存快照，松手一次性压栈）、`remove(at:)`、`updateStyle(at:colorIndex:strokeWidth:fontSize:)`。
- **UI（接入）**：
  - `Sources/UI/Overlay/OverlayWindow.swift`：
    - `EditGesture` 扩展 `.moveAnnotation(index:handle:startPoint:initialAnnotation:)`；
    - 新增 `selectedAnnotationIndex: Int?`、`editingTextAnnotationIndex: Int?`（原地改字期间绘制层跳过原文字，防止重影）；
    - 绘制选中高亮与 Apple 圆形操控柄（与选区 8 向手柄同源视觉语言）；
    - `keyDown` 处理 `Delete`/`Backspace`、选中态方向键微调与 `Esc` 逐级退栈。
  - `Sources/UI/Overlay/OverlayController.swift`：
    - 工具栏改色/改线宽回调同步调用 `overlayView.applyStyleToSelectedAnnotation(...)`；
    - 撤销/重做/切换标注工具时安全收敛 `selectedAnnotationIndex`。
- **单测**：新增 `scripts/TestAnnotationEditingMain.swift` + `scripts/test-annotation-editing.sh`，覆盖全部 7 种 Shape 的命中测试、顶层优先、描边环穿透、操控柄拉伸与单步撤销语义。

### 2.2 功能 #2：随手拖拽出图（Drag-out）

#### 交互设计（三处高频入口全覆盖）
1. **右下角导出 Toast 卡片**（[CaptureToast.swift](file:///Users/qianyuchen/work/screenshot/snapcut/Sources/UI/Notification/CaptureToast.swift)）：
   - 按住卡片/缩略图拖动 `≥ 5pt` 即可直接拖出 PNG 文件到飞书 / Slack / 浏览器上传框 / Finder / Figma；
   - 拖拽期间冻结自动消失倒计时，松手结束后自然退场；轻点 `< 5pt` 仍保持「点击重新打开编辑器」语义；
   - 卡片副标题提示微调为 `W × H · 点击编辑 / 拖出`（仅可交互态），且即便无 `onClick` 的通知图也开放拖拽。
2. **桌面贴图（Pin）**（[PinContentView.swift](file:///Users/qianyuchen/work/screenshot/snapcut/Sources/Adapters/Pin/PinContentView.swift) & [PinWindowController.swift](file:///Users/qianyuchen/work/screenshot/snapcut/Sources/Adapters/Pin/PinWindowController.swift)）：
   - 保持普通拖动 = 移动贴图 / 磁吸拼贴、双击 = 缩放、`⌥+拖` = 拆组等既有直觉不变；
   - 在右上角悬停按钮组（关闭按钮与实况文本按钮左侧）新增同款 20×20 圆形**「拖出文件」手柄按钮**（`arrow.up.right` / `square.and.arrow.up`），按住该按钮拖动 `≥ 4pt` 即刻发起系统原生文件拖拽（悬停 tooltip：`按住拖出图片文件`）；
   - 同时支持 **`⌃+拖拽`（Control + 拖贴图本体）**作为键盘党随手拖出快捷手势。
3. **视觉记忆库卡片（`⌥⌘V` Spotlight）**（[HistorySpotlightPanel.swift](file:///Users/qianyuchen/work/screenshot/snapcut/Sources/UI/History/HistorySpotlightPanel.swift)）：
   - 在 `HistoryCardView` 上按下并拖动 `≥ 6pt`，直接以历史记录已落盘的 `final.png` 文件 URL 发起原生 `NSDraggingSession`（零重复编码，0ms 起拖）；
   - 拖拽会话进行中挂起窗口失焦自动关闭，拖放完成后自动恢复正常收起逻辑；单击选中 / 双击复制 / 右键菜单完全保留。

#### 架构落位
- **新增共享拖拽底座**：`Sources/UI/Export/ImageDragHelper.swift`
  - `@MainActor final class ImageDragCoordinator: NSObject, NSDraggingSource` 单例（遵循 AppKit 铁律：`draggingSession` 期间 source 绝不能提前释放）；
  - 统一 `beginImageDrag(cgImage:suggestedName:from:event:previewSize:onStart:onEnd:)` 与 `beginFileDrag(fileURL:previewImage:from:event:previewSize:onStart:onEnd:)`；
  - 临时 PNG 写入 `FileManager.default.temporaryDirectory/SnapcutDrag/`（带 2x Retina DPI 元数据，自动滚动清理超过 20 个旧临时文件防堆积）；
  - 生成带圆角轻影的精致缩略拖拽影像，负载使用标准 `NSURL`（`public.file-url`，与 Finder 拖出逐字等价，兼容全生态 App）。

### 2.3 功能 #3：选区放大镜一键取色闭环（`C` + `⇧C` + 色卡 Toast）

#### 现状与打磨点
[OverlayWindow.swift](file:///Users/qianyuchen/work/screenshot/snapcut/Sources/UI/Overlay/OverlayWindow.swift) 与 [FrozenSampler.swift](file:///Users/qianyuchen/work/screenshot/snapcut/Sources/UI/Overlay/FrozenSampler.swift) 已有 `C` 复制 HEX 的雏形，但缺少格式切换与视觉确认，用户按 `C` 后遮罩直接静默消失，无从确认是否复制成功及具体色值。

#### 交互设计
1. **三格式实时切换（`Shift+C`）**：
   - `HEX`（默认）：`#2F7CF6`
   - `RGB`：`rgb(47, 124, 246)`
   - `HSL`：`hsl(217, 92%, 57%)`
   - 选区态按 **`⇧C`** 循环切换格式，放大镜读数区实时切换显示当前格式与色值（自动加宽面板适配 RGB/HSL 长度，不截断），并记住本次会话/全局偏好（`UserDefaults` 轻量持久化）；
2. **一键复制 + 色卡轻提示 Toast（`C`）**：
   - 选区态按 **`C`**（不含 `⌘`、`⇧`）复制当前格式的色值文本到剪贴板，播放轻柔反馈（若用户开启截图音效），关闭截图遮罩，并在屏幕右下角弹出 **极简色卡液态玻璃 Toast**：左侧圆角色块芯片（真实采样颜色 + 发丝边）+ 主行等宽色值（如 `#2F7CF6`）+ 副行 `已复制色值 · RGB(47, 124, 246)`，2.2s 自动柔和淡出；
3. **放大镜底栏可读性优化**：
   - 底栏提示清晰标注 `C 复制 · ⇧C 切换`，坐标行使用等宽对齐，确保在 HEX / RGB / HSL 三种长度下排版紧凑美观。
