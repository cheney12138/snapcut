# 多截图合并（拼贴 Collage）功能设计

> 状态：草案（等用户确认形态方向后进入实施）
> 来源：用户需求 2026-11-15「截图之后 pin 在屏幕上，然后合并成一整张，支持编辑（框选/序号/文字）」

## 1. 本质定义

不是「拼接长图」，是**排版**：把多次截取的碎片在一个自由画布上组织成一张图，
再叠加一层统一标注，导出为单张 PNG。

## 2. 功能形态：自由画布 + 磁性吸附 + 统一标注

三个层次：

1. **贴图层（下）**：每张截图是自由浮块——拖动/缩放/旋转/层级调整；
   **分镜格布局（用户裁定 2026-11-15）**：拖近时吸附到「带均匀间隙的格位」
   （gutter 默认 16pt，8pt 栅格），不是零间隙贴合——无缝贴在一起不可读，
   漫画分镜式间隙让多图结构一眼可辨。
   - 贴片默认带**分镜框**（0.5pt 描边 + 圆角 2，漫画分镜感，可关）
   - 吸附预览：拖动时显示目标格位虚线框 + 间隙
   - 自由位置仍然允许（吸附是辅助不是强制，松手前按 Esc/⌘ 拖可跳过吸附）
   - 可选：Stitcher 行匹配做「内容重叠时的像素对齐建议」（两张图同内容区域时）
2. **标注层（上）**：整张画布统一标注——矩形框选跨图、序号跨图、文字任意位置、
   箭头/马赛克/画笔全套（复用现有 CGRenderer，所见=所得）。
3. **导出**：框选画布范围（或自动内容范围）→ composite 成单 PNG → 复制/保存
   （复用 CGRenderer.composite）。

## 3. 操作路径（复用 pin，不发明新入口）

```
截图 → 编辑器「贴图」→ 图A pin 到屏幕
截图 → ... → 图B pin 到屏幕
合并触发（三选一，用户用哪个都行）：
  a) 图B ⌥拖到图A 上松手 → 成组
  b) pin 图右键 →「合并到拼贴」
  c) 按住 ⌘ 框选多张 pin 图 → 右键成组
拼贴画布窗口：
  - ⌘⇧A 连续截图 → 新图自动飞入画布（边截图边排）
  - 拖动贴片排布（吸附线可视化）
  - 点「标注」进入标注模式：全套工具照常画
  - ⌘⏎ / 「导出」→ 圈选范围 → 复制/保存
```

关键交互决策（待确认）：
- **pin 拖近自动成组**（省掉显式「创建拼贴」步骤）vs CleanShot 式显式建画布
- **画布激活时 ⌘⇧A 自动入画布**（连续工作流）
- **吸附目标是分镜格位（带 16pt 间隙），不是零间隙**——无缝贴片不可读（用户裁定）
- 画布背景：间隙的填充色可选（透明/白/深色，导出随选）

## 4. 技术形态（六边形落位）

```
Core/Domain（纯值类型，无 AppKit）：
  CollageDocument        拼贴文档：贴片数组 + 标注数组 + 画布范围
    - Piece: id / imageRef / frame / rotation / z
    - 变更走不可变更新（undo/redo 复用 AnnotationStore 思路）
  SnapGeometry           分镜格吸附纯几何（格位计算：行列吸附 + gutter 16pt，
                          SelectionGeometry 同款风格；吸附目标=格位不是零距离）
Core/Ports：
  CollageStoring         文档暂存/恢复（会话级，可先内存实现）
Adapters/UI：
  CollageWindow          画布窗（贴片手势 + 吸附高亮 + 标注层切换）
  PinWindow 扩展          右键菜单 + ⌥拖合并手势 + 成组 drop target
  CollageExporter        范围框选 + composite（复用 CGRenderer）
```

## 5. 实施切分（并行子任务）

| 子任务 | 内容 | 规模 | 依赖 |
|---|---|---|---|
| C1 Core 文档+几何 | CollageDocument + SnapGeometry + Port | ~250 行 | 无（先行） |
| C2 画布窗口 | 渲染/贴片手势/吸附线/连续截图入口 | ~600 行 | C1 |
| C3 Pin 合并手势 | 右键「合并」+ ⌥拖 + drop 画布 | ~200 行 | C1（与 C2 可并行，接口先约好） |
| C4 导出 | 范围框选 + composite + toast | ~150 行 | C1（与 C2/C3 并行） |

## 6. 已有能力盘点（复用面）

- PinWindow：缩放拖动贴图（双击复位、滚轮缩放）→ 贴片手势直接参考
- Stitcher：行签名重叠检测 → 可选的像素对齐辅助
- CGRenderer + AnnotationStore：标注全套 + undo → 标注层整体复用
- PinContentView：pin 渲染 → 画布贴片渲染参考
