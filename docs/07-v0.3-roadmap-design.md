## 0. 背景与阅读指南（给后端/Java 视角的映射）

Snapcut 遵循**六边形架构（Hexagonal Architecture）**，由 `./scripts/check-architecture.sh` 强制守护：

| Snapcut 分层目录 | 类比 Java / Spring 工程 | 职责与硬性纪律 |
| :--- | :--- | :--- |
| `Sources/Core/Domain/` | `domain` / 纯 POJO + 纯算法 Service | 仅允许 `Foundation` / `CoreGraphics`；**严禁** import `AppKit` / `Vision` / `ScreenCaptureKit`，可独立单测 |
| `Sources/Core/Ports/` | `port` / `interface` 协议层 | 定义能力接口（如 OCR、存储、剪贴板），UI 层只依赖接口不直连系统 SDK |
| `Sources/Adapters/` | `infrastructure` / `adapter` 实现层 | 对接 macOS 系统框架（Vision OCR、ScreenCaptureKit、文件存储、贴图窗口等） |
| `Sources/UI/` | `controller` / `view` 交互层 | 负责覆盖层画布、悬浮工具栏、设置面板等视觉交互 |
| `Sources/App/` | `Application` / DI 装配根 | `AppCoordinator` 与 `Dependencies` 组装所有适配器与状态机 |

**为什么写这份文档**：  
v0.1–v0.2 已完成「快、稳、像 Apple 原生」的基础体验，但截图仍是「截完即丢」的一次性动作。本文规划 **4 大模块（3 个核心支柱 + 1 个现有能力打穿）**，全部保持极简克制（不做录屏、不做账号云同步），并拆解到可直接开工、可验收、可回溯的 **Task 级别**。

**标准开发工作流（每做一个 Task 固定闭环）**：
1. **确认范围**：先对齐该 Task 的交互与边界（不动无关模块）。
2. **先 Core 后 UI**：纯规则/算法先落 `Sources/Core/Domain/` 并跑独立验证脚本，再接 Adapter 与 UI。
3. **验证门槛**：`./scripts/check-architecture.sh` → 专项单测 → `make dev` → `./scripts/restart.sh` → `/usr/bin/log` 检查启动与事件日志。
4. **文档留痕**：更新本文对应 Task 状态 + 在 [CHANGELOG.md](../CHANGELOG.md) 追加条目。

## 2. M1 · 高频刚需：智能一键脱敏（Auto-Redact）

### 2.1 产品目标与交互设计

**解决痛点**：日常把截图发给 AI（ChatGPT / Claude / Cursor）、发工作群或贴 GitHub Issue 时，频繁需要手动拉 4–5 个马赛克框去遮挡邮箱、手机号、API Key（`sk-...`）、Bearer Token、内网 IP、密码参数等，慢且容易漏。

**极简交互流（零界面膨胀）**：
1. 选区进入编辑态后，点击工具栏「马赛克」或按 `5`；
2. 仅当选中马赛克工具时，在工具栏上方轻浮一枚极简小胶囊 **`✦ 智能打码`**（或快捷键 `⇧M`）；
3. 点击后，本地 Vision OCR 识别当前选区内全部文字及其精确坐标框（100% 离线，约 80–150ms），命中敏感规则的词条**自动生成对应位置的马赛克标注**写入 `AnnotationStore`（天然支持 `⌘Z` 一键撤销！）；
4. **可纠偏**：自动生成的脱敏框在选区上短暂闪一下轻蓝轮廓提示命中数量（如 HUD `已自动脱敏 3 处`），点击任意已打码区域可单独取消该处脱敏（或在 `AnnotationStore` 直接 `⌘Z` 退回）。

### 2.2 架构落位

- **Core/Domain（新增）**：`Sources/Core/Domain/SensitiveTextDetector.swift`
  - 纯值类型输入：`OCRTextBlock(text: String, normalizedBox: CGRect)`（Vision 归一化坐标，左下原点）
  - 纯规则引擎：识别 `email` / `chinaPhone` / `apiKey`（`sk-`、`ghp_`、`AKIA`、`Bearer `、`xoxb-` 等常见密钥前缀与高熵长串）/ `ipv4` / `jwt` / `urlSecretParam`（`token=`、`key=`、`secret=`、`password=`）
  - 纯输出：`[SensitiveMatch(kind, range, pixelOrLocalRect)]`
- **Core/Ports（扩展）**：`Sources/Core/Ports/Ports.swift`
  - 在 `TextRecognizing` 协议增加 `func recognizeBlocks(_ image: CGImage) async throws -> [OCRTextBlock]`（保留原有 `recognize(_:)` 不破兼容）
- **Adapters/OCR（扩展）**：`Sources/Adapters/OCR/TextRecognizer.swift`
  - 复用 `VNRecognizeTextRequest`，在原有 `topCandidates(1)` 上直接调用 `candidate.boundingBox(for: range)` 提取精确词级/行级坐标框（Vision 原生支持，零第三方依赖）
- **UI（接入）**：`Sources/UI/Editor/ToolbarPanel.swift`、`Sources/UI/Overlay/OverlayController.swift`、`Sources/UI/Overlay/OverlayWindow.swift`
  - 触发脱敏 → 把命中的局部矩形批量追加为 `.mosaic(rect)`（一次操作打包或逐条入 `AnnotationStore`，支持撤销）

| Task ID | 任务内容 | 涉及文件 | 验收标准 | 状态 |

## 3. M2 · 核心护城河：视觉记忆库（Visual Memory & 可反悔重编）

### 3.1 产品目标与交互设计

**解决痛点**：
1. 昨天截的一条报错、前天截的一张接口参数/发票，在剪贴板被覆盖后就找不回来了；
2. 刚把带箭头的截图发到群里，发现箭头画歪了或漏打了一处码，只能重新再截一遍、重新画一遍。

**极简交互流**：
1. **静默建索引（零感知）**：每次截图/拼贴导出落入 `HistoryStore` 时，后台低优先级（`.utility`）静默跑一次本地 Vision OCR，把 `ocrText + sourceAppName + windowTitle + timestamp` 写入本地索引（`index.json`）；
2. **Spotlight 速搜浮层（全局热键，默认 `⌥⌘V`）**：
   - 呼出一张 Apple Liquid Glass 横向/网格速搜浮窗（顶部搜索框 + 缩略图流 + 命中文本高亮）；
   - 输入关键词（如 `502`、`Figma`、`发票`），毫秒级过滤历史截图；
   - 键盘方向键切换，**`Enter` 直接复制原图**、**`⌘E` 重新打开编辑**、**`⌘P` 直接贴到桌面（Pin）**、**`⌘C` 复制识别文字**、**`Esc` 关闭**；
3. **非破坏性「可反悔矢量重编」**：
   - 最近 20 条历史记录同时保存「干净底图 + `AnnotationModel[]` 矢量 JSON」；
   - 点击 Toast 或从历史按 `⌘E` 重开时，直接恢复完整的矢量标注层——支持继续 `⌘Z` 撤销刚才的箭头/文字/马赛克，或补标后重新导出！

### 3.2 架构落位

- **Core/Domain（扩展 & 新增）**：
  - 扩展 `Sources/Core/Domain/AnnotationModel.swift`：为 `AnnotationModel` / `Shape` 补齐 `Codable`（纯值类型 JSON 序列化，方便落盘历史）
  - 新增 `Sources/Core/Domain/HistoryRecord.swift`：定义 `HistoryRecord(id, createdAt, width, height, sourceApp, windowTitle, ocrText, hasEditableAnnotations)` 与纯内存检索过滤函数（关键词分词匹配 + 按时间倒序）
- **Adapters/History（扩展）**：`Sources/Adapters/History/HistoryStore.swift`
  - 存储结构升级（向后兼容旧历史目录）：每条记录存 `final.png`（导出成品），若带编辑会话额外存 `base.png` + `annotations.json`；
  - 异步后台 OCR 索引队列（串行低优先级，不抢占前台截图 CPU）
- **UI（新增）**：`Sources/UI/History/HistorySpotlightPanel.swift`
  - 无边框 `NSPanel` + `AdaptiveGlassView` + 顶部搜索框 + 缩略图卡片列表 + 键盘全导航（`↑↓←→ / ↩ / ⌘E / ⌘P / Esc`）

## 4. M3 · 传播卖点：克制的一键画框美化（Smart Backdrop）

### 4.1 产品目标与交互设计

**解决痛点**：直接贴进文档/群聊/PR 的裸截图边缘生硬、四周留白不齐，观感廉价；专门开 Figma/Xnapper 又打断心流。

**极简交互流**：
1. 在编辑器工具栏新增一枚轻量图标按钮（如 `sparkles.rectangle.stack` / 快捷键 `B`），默认关闭（不改变日常极速裸截图习惯）；
2. 开启后，在工具栏上方展开一条极简磨砂微调胶囊：
   - **6 套克制 Apple 风格背景色板**（浅雾灰、柔白、深曜石、macOS 壁纸渐变 × 3）；
   - **边距档位**（紧凑 `24pt` / 标准 `40pt` / 展示 `64pt`）；
   - **比例开关**（`自动` / `16:9` / `4:3`）；
   - **自动均衡留白开关**（检测截图四边边缘颜色，自动补齐不对称内边距，视觉居中）；
3. 导出（复制 / 保存 / Pin）所见即所得，圆角 + 双层柔影 + 背景一次烤入高清 PNG。

### 4.2 架构落位

- **Core/Domain（新增）**：`Sources/Core/Domain/BackdropStyle.swift`
  - 纯值类型：`BackdropStyle(enabled, preset, padding, cornerRadius, aspectRatio, autoBalance)` + 预设调色板 + 画布几何计算（`canvasSize`, `imageRect`）
- **UI/Annotate（扩展）**：`Sources/UI/Annotate/CGRenderer.swift`

- **UI/Editor（接入）**：`Sources/UI/Editor/EditorSession.swift`、`Sources/UI/Editor/ToolbarPanel.swift`、`Sources/UI/Overlay/OverlayWindow.swift`

## 6. 变更与回溯纪律

1. **先设计后写代码**：每个里程碑开工前，在本文件确认细节或补充边界用例。
2. **一 Task 一闭环**：每次只聚焦 1–2 个关联 Task，完成构建、实机验证、日志核对后再勾选状态。
3. **强制更新日志**：任何代码提交/合并前，必须在根目录 [CHANGELOG.md](../CHANGELOG.md) 按日期记录「变更摘要 + 根因/决策 + 涉及文件」，确保非 Swift 背景也能随时清晰回溯整个桌面端演进脉络。
