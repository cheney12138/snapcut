# Snapcut 工具栏精简重构与未来录制能力规划（需求规格说明书）

## 1. 背景与核心问题

当前 `ToolbarPanel` 在「标准」尺寸（`buttonSide = 36`）下共有 **23 个子视图（18 个交互单元 + 5 条分隔线）**，实测总宽约 **970pt**（大号档位超过 **1100pt**）：

```text
[7 标注工具 ≈282pt] | [5 色点 ≈97pt] | [线宽滑杆 76pt] | [撤销 重做 ≈77pt] | [滚动 取字 贴图 画框 显隐 ≈200pt] | [复制 保存 取消 ≈118pt]
```

面临两个现实问题：
1. **属性区常驻占宽过高**：颜色圆点 + 线宽滑杆 + 两侧分隔线共占约 **205pt**（超整条栏宽 1/5），但用户选好常用颜色/粗细后单次截图极少频繁改动；且尚未选择标注工具（`.none`）时该区域完全闲置。
2. **动作区未来仍会扩容**：后续计划加入 **录屏（MP4）** 与 **GIF 录制**。若继续平铺进同一条单行栏，在小选区（例如 `400×300` 弹窗）或笔记本小屏上会严重超宽。

**设计原则（已对齐确认）**：
- **不做横向滚动条**：悬浮玻璃条内横向滚动会裁切图标边缘、增加寻址摩擦。
- **主栏只留高频核心动作**：常用能力一点击即达，低频拓展与未激活的属性按需呈现。
- **不破坏已有快捷键语义**：所有收纳进菜单或上下文胶囊的功能，其键盘快捷键（`1–7`、`B`、`H`、`O`、`P`、`S`、`⇧M` 等）全部保持全局直达。

## 2. 已确认的产品决策

| 决策项 | 结论 | 说明 |
|---|---|---|
| **颜色 + 线宽** | **采用方案 B（按工具上下文浮出）** | 主工具栏彻底移除常驻色点与线宽滑杆；仅当选中具体标注工具时，在主栏旁自动展开对应属性胶囊。 |
| **隐藏工具栏 (`H`)** | **不常用 → 收进 `•••` 更多菜单** | 从主栏移除独立按钮，放进更多菜单；按 `H` 键仍可零延迟切换显隐。 |
| **画框美化 (`B`)** | **不常用 → 收进 `•••` 更多菜单** | 从主栏移除独立按钮，放进更多菜单；开启画框后其微调胶囊 `SmartBackdropPillPanel` 仍正常联动；按 `B` / 快捷键仍可直达。 |
| **录屏 / GIF** | **录屏较常用、GIF 不常用** | Phase 2 接入时：**录屏**在主栏占 1 个入口（或选区前分流）；**录制 GIF** 收进 `•••` 更多菜单。 |
| **高频常驻动作** | **保留主栏直达** | 7 标注工具、撤销/重做、滚动截图、取字（OCR）、贴图（Pin）、复制/保存/取消 全部保留主栏一点击即达。 |

## 3. 详细交互与视觉规格

### 3.1 优化后的主工具栏布局（Phase 1）

按从左到右 4 个逻辑分区排布，共 **15 个交互单元 + 3 条分隔线**（标准档宽约 **685pt**，比现状 ~970pt 净省 **~285pt**）：

```text
[1 2 3 4 5 6 7]  |  [撤销  重做]  |  [滚动  取字  贴图  •••]  |  [复制(主)  保存  取消]
   标注工具组(7)       历史组(2)          动作与扩展组(4)               输出组(3)
```

**对比收益（标准档 `buttonSide = 36`）**：

| 阶段 | 主栏单元数 | 预估宽度 | 相比现状 |
|---|---|---|---|
| 现状 | 18 单元 + 5 分隔 | ~970 pt | — |
| **Phase 1（本轮）** | **16 单元 + 3 分隔** | **~685 pt** | **-285 pt（-29%）** |
| Phase 2（+录屏，GIF 进 `•••`） | 17 单元 + 3 分隔 | ~726 pt | -244 pt（仍远短于现状） |

> 注：当用户触发「录屏」或「录制 GIF」进入录制准备/录制中状态时，静态标注主栏退场，原地切换为极简录制控制条（仅包含尺寸读数、帧率/声音/鼠标开关、开始/停止录制、取消），不存在两套按钮并存的问题。

### 3.2 方案 B：上下文工具属性胶囊（`SmartToolAttributePillPanel`）

#### 3.2.1 显隐规则
- **默认态（`session.currentTool == .none`）**：上方 **不显示** 任何属性胶囊（主栏保持极致干爽）。
- **激活态（`session.currentTool != .none`）**：选中任一标注工具后，立即在主工具栏上方 `8pt` 处浮出与该工具匹配的轻盈玻璃胶囊（与主工具栏同源 `Mat.fixedLightCrystalBlur` + `OuterShadowView(.pill)`）。
- **再次点击已选中工具 / 按同数字键切回 `.none` / 按 `H` 隐藏工具栏**：属性胶囊随主栏同步收起。
- **拖拽/绘图标注瞬间**：保持现有交互体验——用户开始在画布上拖拽画箭头/框时，不抢焦点；松手后保持可见方便连续微调或继续画下一笔。

#### 3.2.2 按工具精准映射属性（基于 `CGRenderer.swift` 真实渲染依赖）

> 核对现有渲染器：`sequence` 直径随 `strokeWidth` 缩放；`mosaic` 块大小由 `strokeWidth` 控制（`max(8, strokeWidth * 4)`）；`text` 使用颜色与 `textFontSize`（12 / 14 / 17 / 21）。

| 当前选中工具 | 属性胶囊内容（从左到右） | 说明 |
|---|---|---|
| **矩形 / 椭圆 / 箭头 / 高亮** | `[5 色圆点] | [粗细滑杆 2–10pt]` | 完整覆盖颜色与线宽调节。 |
| **序号（`.sequence`）** | `[5 色圆点] | [粗细/圆标大小滑杆 2–10pt]` | 同上，`strokeWidth` 直接控制序号徽标直径。 |
| **文字（`.text`）** | `[5 色圆点] | [字号 4 档：12 · 14 · 17 · 21]` | 同步读写 `session.textFontSize`；未起输入框时即可预设字号，解决此前“不点出输入框就看不到字号”的断层。 |
| **马赛克（`.mosaic`）** | `[块大小滑杆 2–10pt] | [✦ 智能打码 ⇧M]` | **合一设计**：将现有 `SmartRedactPillPanel` 并入马赛克属性胶囊，同时开放马赛克块大小调节，消除双胶囊重叠。 |

#### 3.2.3 锚点定位与多胶囊避让规则
1. **横向对齐**：默认中心对齐当前激活的工具按钮 `button.midX`（若胶囊较宽，以主栏左/右边缘为边界做屏幕 `visibleFrame` 夹紧，保证不超出屏幕）。
2. **纵向优先级**：
   - 在截屏编辑态（`OverlayController`，主栏通常在选区下方）：优先在**主栏上方 `8pt`** 展开；若主栏上方空间不足（例如主栏因贴底而翻到了选区上方，或贴近屏顶），则自动翻到**主栏下方 `8pt`**。
   - 在拼贴编辑窗（`CollageEditorWindowController`，主栏在窗顶上方）：同样先试主栏上方 `8pt`，放不下时再避让到主栏与窗顶间隙外侧或窗内侧合适位置，不压住主栏本身。
3. **与 `SmartBackdropPillPanel`（画框美化胶囊）共存**：
   - 画框美化开关打开且当前也选中了标注工具时：属性胶囊优先贴紧主栏上方第 1 层（`bar.maxY + 8`），`SmartBackdropPillPanel` 自动上避到第 2 层（或错开水平区间），沿用并完善现有 `avoidRect` 机制。
4. **与文字字号面板不重复**：
   - 选中 `.text` 工具并在画布点击进入实际文字输入（`NSTextField` 激活）时：若属性胶囊已提供 `12 / 14 / 17 / 21` 档位且实时同步当前编辑框字号，可决定保留同步或收敛旧的独立浮窗字号条，避免屏幕上同时出现两套字号选择器。

### 3.3 `•••` 更多操作菜单（收容低频动作）

#### 3.3.1 按钮外观与状态反馈
- 位于主栏动作区最右侧（`贴图` 之后、输出分隔线之前），使用 SF Symbol `ellipsis`（`TBIcon.Kind.more`）。
- **视觉状态提示**：当菜单内某项处于**开启状态**（例如已通过快捷键 `B` 或菜单开启了「画框美化」），`•••` 按钮可显示温和的激活态高亮（或微蓝指示），让用户知道“当前有扩展效果生效中”。

#### 3.3.2 菜单项清单（按宿主能力裁剪）

不同宿主复用 `ToolbarPanel` 时能力不同，需通过轻量 `Capabilities` 配置声明（不让拼贴编辑器出现不可用的录屏/滚动项）：

| 菜单项 | 快捷键提示 | 截图编辑器 | 拼贴编辑器 | 说明 |
|---|---|---|---|---|
| **画框美化**（带勾选态 ✓） | `B`（可自定义/沿用） | ✅ | ✅ | 切换 `backdropStyle.enabled`，开启后正常浮出 `SmartBackdropPillPanel` 调色板/边距/比例。 |
| **隐藏工具栏** | `H`（读 `editorHotkeys["toggleVisibility"]`） | ✅ | ✅ | 执行 `.toggleVisibility`，提示按快捷键可唤回。 |
| *分隔线* | — | — | — | — |
| **录制 GIF** *(Phase 2)* | — | ✅ | ❌ | Phase 1 先不展示空占位，Phase 2 实装后接入。 |

> 说明：**不要在 Phase 1 菜单里放灰色的「敬请期待：GIF 录制」占位项**，遵循克制原则，功能未实装前不出现假入口。

#### 3.3.3 快捷键兼容与补齐检查
- 现有 `EditorKeyRouter` 支持 `undo / redo / toggleVisibility / ocr / pin / save / done / cancel / scroll` 与数字 `1–7`。
- 画框美化目前 tooltip 上写着 `画框美化 B`，需确认或补充 `B` 键 / `editorHotkeys["backdrop"]` 的一致行为（点击 `•••` → `画框美化` 与键盘触发等价）。
- 隐藏工具栏 `H`：由于 `•••` 菜单收起了常驻 `eye` 按钮，当用户按 `H` 隐藏工具栏后，再次按 `H` 唤回的交互完全保持不变；可在 Toast 或初次隐藏时维持现有轻量提示体验。

### 3.4 Phase 2 预留：录屏（MP4）与 GIF 录制架构边界

为避免 Phase 1 的代码改动把 Phase 2 路堵死，提前约定接口边界（本轮仅落文档，不实现录制内核）：

1. **入口落位**：
   - **录屏（视频）**：Phase 2 在动作区 `滚动截图` 旁增加 1 枚 `录屏` 按钮（图标 `record.circle` / `video`），主栏宽度约 `726pt`，依然可控。
   - **录制 GIF**：放入 `•••` 更多菜单（同时在状态栏托盘菜单提供快捷入口）。
2. **模式切换（状态机收口）**：
   - 用户触发 `录屏` 或 `录制 GIF` 后，若当前选区尚无标注，直接退出静态标注模式并切换为 **录制控制栏（RecordingControlBar）**：
     - 保留选区边框作为录制区域框（支持开录前微调大小）；
     - 控制栏仅显示：`[选区尺寸] | [帧率/系统音频/麦克风开关] | [● 开始录制] [取消]`。
   - 若用户已经在选区上画了静态标注再点录制：确认是直接带标注录制屏幕（隐藏静态编辑框进入录制）还是提示放弃标注，Phase 2 立项时再最终拍板。
3. **六边形架构落位**：
   - `Sources/Core/Ports/` 新增 `ScreenRecording` 端口协议；
   - `Sources/Adapters/Recording/` 对接 `SCStream` + `AVAssetWriter`（MP4）与 `CGImageDestination`（GIF）。

## 5. Phase 1 验收标准（DoD）

1. **主栏宽度显著收敛**：标准档下主栏由 ~970pt 降至 ~685pt 左右，在 `400×300` 选区及小屏下居中完整呈现，无裁切。
2. **未选工具零浮条**：刚拖完选区进入 `.none` 时，主栏上方/下方无多余悬浮胶囊；只有主工具栏一条。
3. **按工具精准浮出属性**：
   - 选矩形/椭圆/箭头/序号/高亮 → 浮出 `[5 色点 + 线宽滑杆]`；
   - 选文字 → 浮出 `[5 色点 + 字号 12/14/17/21]`，调节实时作用于文本；
   - 选马赛克 → 浮出 `[块大小滑杆 + ✦ 智能打码 ⇧M]`，不出现颜色选择。
4. **低频项收敛不丢能力**：
   - `•••` 菜单可正常切换「画框美化」（带勾选状态）与「隐藏工具栏」；
   - 键盘 `H` 隐藏/唤回工具栏、画框美化快捷键及所有 `1–7`、`O`、`P`、`S`、`⇧M` 全部正常。
5. **双向边界与双宿主稳健**：
   - 工具栏贴屏幕顶/底边缘时，属性胶囊自动向可用一侧翻转；
   - 打开「画框美化」且同时选中工具时，两个上浮胶囊不互相遮挡；
   - 拼贴编辑器打开时工具栏与属性胶囊同样稳定可用，无越界或崩溃。
6. **架构与实机检查**：`./scripts/check-architecture.sh` 通过、`make dev` 零报错零新警告、`./scripts/restart.sh` 重启存活且 `/usr/bin/log` 无异常。
